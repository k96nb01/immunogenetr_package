# Ten HLA-A~C~B~DRB3/4/5~DRB1~DQA1~DQB1~DPA1~DPB1 haplotypes and their frequencies in the global population.

Ten HLA-A~C~B~DRB3/4/5~DRB1~DQA1~DQB1~DPA1~DPB1 haplotypes and their
frequencies in the global population.

## Usage

``` r
data(Haplotype_frequencies)
```

## Format

A tibble:

- HLA-A:HLA-DPB1:

  HLA allele names

- Global_Fq:

  haplotype frequencies

- Global_n:

  haplotype observations

- Global_rank:

  haplotype rank
