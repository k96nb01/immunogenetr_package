# Synthetic HLA typing data for 10 individuals for the HLA-A, B, C, DRB1, DRB3/4/5, DQB1, DQA1, DPB1 and DPA1 loci.

Synthetic HLA typing data for 10 individuals for the HLA-A, B, C, DRB1,
DRB3/4/5, DQB1, DQA1, DPB1 and DPA1 loci.

## Usage

``` r
data(HLA_typing_1)
```

## Format

A tibble:

- patient:

  Patients 1-10

- A1:DPB1_2:

  HLA allele names

## Source

Synthetic data from Nicholas K. Brown.
