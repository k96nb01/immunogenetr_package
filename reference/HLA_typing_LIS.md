# Synthetic HLA typing data for 10 individuals for the HLA-A, B, C, DRB1, DRB3, DRB4, DRB5, DQB1, DQA1, DPB1 and DPA1 loci. Data formatted to resemble a HistoTrac table.

Synthetic HLA typing data for 10 individuals for the HLA-A, B, C, DRB1,
DRB3, DRB4, DRB5, DQB1, DQA1, DPB1 and DPA1 loci. Data formatted to
resemble a HistoTrac table.

## Usage

``` r
data(HLA_typing_LIS)
```

## Format

A tibble:

- patient:

  Patients 1-10

- mA1Cd.recipient:mDPB12cd.recipient:

  HLA allele names

## Source

Synthetic data from Nicholas K. Brown.
